Ben Kimim?

Merhaba! Ben Aydın Aydemir, cyberQbit olarak bilinen bir yazılım öğrencisi ve geliştiricisi.

Hem Ankara Üniversitesi'nde Bilgisayar Programcılığı hem de Atatürk Üniversitesi'nde Web Tasarım ve Kodlama alanlarında çift önlisans yapıyorum.

Android mobil uygulamalardan Windows scripting araçlarına, React web uygulamalarından C# .NET backend API'lerine kadar geniş bir yelpazede proje geliştiriyorum. Siber güvenlik, açık kaynak ekosistemi ve kullanıcı odaklı tasarım üçgeninde çalışmayı seviyorum.

Aynı zamanda GitHub Sponsors ve Patreon üzerinden desteklenebilir bir açık kaynak geliştiriciyim.
